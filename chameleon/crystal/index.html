Chameleon Ultra crystal offset

Measures how fast or slow a Chameleon Ultra's 32 MHz crystal runs, against internet time, over USB. To use NTP from the command line instead, run hfxo_ntp.py.

Before you start

  • Chrome or Edge on a computer, with the CU on USB (not Bluetooth).
  • The test firmware below. Stock firmware can't count the crystal's ticks.
  • Close anything else using the CU (e.g. CU App or the Python CLI), and keep it away from readers during the run.
  • Keep this tab open and the computer awake, and stay on the same network.

Firmware

Test firmware: stock v2.3.0 plus command 3125, nothing else (source, branch feat/hfxo-count). Chameleon Ultra only, not Lite. Flashing replaces the firmware; slots and saved cards are kept. Flash stock v2.3.0 back when you're done.
