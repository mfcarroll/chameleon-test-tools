Flipper Zero crystal calibration

Every Flipper's crystal runs a little fast or slow. This page measures your Flipper's crystal against internet time and saves the correction in the RFID detector app, allowing for accurate measurement of a LF reader field's frequency.

How to calibrate

  1. In this page, in Chrome or Edge on a computer. It takes about 30 minutes.
  2. From the command line, with Python: see below.
  3. By hand, if you already know the offset: in the app, press Left for Config, then Set calibration manually.

Plug the Flipper in by USB and close any other connected apps, e.g. qFlipper. Exit any app that's open on the Flipper itself. The page and the script open the RFID detector app automatically.

Command line

flipper_crystal.py does the same measurement using NTP. It finds the Flipper, opens the app, shows its progress there, and saves a good result.

With uv

curl -LO https://mfcarroll.github.io/rfid-test-tools/flipper/crystal/flipper_crystal.py
uv run flipper_crystal.py

uv (or pipx run) installs pyserial automatically.

With Python

pip install pyserial
python3 flipper_crystal.py        # Windows: py flipper_crystal.py

Options: --minutes (default 30), --no-send to only print the result, --server, --log. With more than one Flipper plugged in, add its port, such as COM5 or /dev/ttyACM0.

For developers: the app's CLI command

While the app (v1.5 or later) is running it adds rfid_detector_cal to the Flipper's CLI. Values are in 0.1 ppm, + meaning fast.

  • It replies OK lfcal 64000000 <saved>.
  • r returns <count> <pll>: a 32-bit timer at 64 MHz from the crystal (it wraps every 67 s), and 1 while the clock runs from the crystal. ppm = (counts per second / 64 MHz − 1) × 10⁶.
  • p<elapsed s> <total s> [<estimate> <±>] + Enter updates the progress screen.
  • s<value> + Enter saves a correction and replies SET <value>.
  • Anything else ends the session (STOPPED), including Cancel on the Flipper.
