Connect your Flipper

Plug your Flipper in to USB and close qFlipper. Exit any app that's open on the Flipper itself. This browser-based tool requires Chrome or Edge on a computer. See below for alternative options.

Already know the offset? Set it by hand in the app: press Left for Config, then Set calibration manually.

Command line (Python script)

flipper_crystal.py performs the same calibration using NTP. 

curl -LO https://mfcarroll.github.io/rfid-test-tools/flipper/crystal/flipper_crystal.py
uv run flipper_crystal.py

uv installs pyserial automatically. 

curl -LO https://mfcarroll.github.io/rfid-test-tools/flipper/crystal/flipper_crystal.py
pipx run flipper_crystal.py

pipx installs pyserial automatically. 

curl -LO https://mfcarroll.github.io/rfid-test-tools/flipper/crystal/flipper_crystal.py
pip install pyserial
python3 flipper_crystal.py

On macOS or Linux.

curl.exe -LO https://mfcarroll.github.io/rfid-test-tools/flipper/crystal/flipper_crystal.py
py -m pip install pyserial
py flipper_crystal.py

In PowerShell or the Command Prompt.

Options

--minutes N
How long to measure. 30 by default.
--no-send
Print the result without saving it on the Flipper.
--server HOST
The NTP server. time.cloudflare.com by default.
--log FILE
Write every sample to a file.
PORT
With more than one Flipper plugged in, the one to use, such as COM5 or /dev/ttyACM0.

For developers

The RFID detector app (1.5 or later) adds rfid_detector_cal to the Flipper's CLI while the app is running. Values are in 0.1 ppm, + meaning fast.

  • It replies OK lfcal 64000000 <saved>.
  • r returns <count> <pll>: a 32-bit timer at 64 MHz from the crystal (it wraps every 67 s), and 1 while the clock runs from the crystal. ppm = (counts per second / 64 MHz − 1) × 10⁶.
  • p<elapsed s> <total s> [<estimate> <±>] + Enter updates the progress screen.
  • s<value> [<±>] + Enter saves the calibration and its ±. The app replies SET <value> once it has saved it, otherwise ERR <reason>.
  • Anything else ends the session (STOPPED), including Cancel on the Flipper.
