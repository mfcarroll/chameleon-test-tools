Chameleon Ultra crystal offset

Times the CU's 32 MHz crystal against an internet time server, over USB, in the browser. To use NTP instead, run hfxo_ntp.py from the same folder.

Before you start

  • Chrome or Edge on a desktop (Web Serial). Use USB; Bluetooth adds too much jitter.
  • Firmware with command 3125 (the crystal tick counter). Stock firmware doesn't have it: flash the test firmware below first.
  • Close anything else using the CU's port (ChameLab, the Python CLI). Keep the CU away from readers and don't run LF commands during the run.
  • Keep this tab open and the computer awake. Don't switch networks mid-run: the result assumes the path to the time server stays the same.

Firmware

Test firmware: stock v2.3.0 plus command 3125, nothing else (source, branch feat/hfxo-count). Chameleon Ultra only, not Lite. Flashing replaces the firmware; slots and saved cards are kept. Flash stock v2.3.0 back when you're done.
