Chameleon test tools

Tools for testing Chameleon Ultra hardware, each with the test firmware it needs, flashable from the page. Source: mfcarroll/chameleon-test-tools.

Crystal offset The 32 MHz crystal's offset in ppm, timed against an internet time server over USB. Needs stock v2.3.0 + command 3125. FSK self-trim (experiment) Test firmware for HID Prox, Paradox and ioProx emulation: copy a card into several slots with different modes, compare them at a reader, and read back what the CU learned.
